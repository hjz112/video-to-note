# 视频笔记规范

这份文档规定「原材料 → 知识笔记」的整理标准。

之所以独立于 SKILL.md：笔记规范高度个人化且会频繁调整，
把它和下载流程耦合会迫使每次改格式都动 skill 本身。

## 输出

- 文件名固定 `summary.md`，放在 `video-downloader-enhanced` 产出的视频目录内。
- 单文件交付，不拆分。

## 结构（按此顺序）

```markdown
# <视频标题>

> 原视频：<平台> · <作者> · <发布日期> · <链接>

## 基本信息
| 项 | 值 |
|---|---|
| 作者 / 发布 / 时长 / 画质 / 互动数据 / 标签 | ... |

## 一句话总结
≤ 50 字，讲清这条视频到底解决了什么问题。

## 核心内容
按视频自身逻辑分点。教程类按流程步骤，观点类按论点。

## 关键要点 / 可复用方法
有则写，没有就整节省略。

## 存疑与不足
ASR 误识别、口播含糊、信息缺失的地方，明确列出。

## 标签
#标签1 #标签2
```

原视频链接放在**标题下方第二行**（不是文末），引导回平台观看——
观看时长和互动对创作者是真实收益。

## 写作原则

1. **校验优先** — ASR 转写必然有错。专业名词、人名、产品名按常识校正；
   拿不准的保留原文并标注，不要硬猜。
2. **压缩而非搬运** — 禁止整段复制转写文本。笔记是信息提炼，
   篇幅应远小于原文。
3. **不臆造** — 视频没说的内容不写。确需推断时明确标注「（推断）」。
4. **保留原名** — 专有名词、英文缩写、产品名保留原始写法，
   不要翻译成中文。
5. **标注存疑** — 转写质量差、关键信息听不清时，在「存疑与不足」里说明，
   而不是静默略过。

## 篇幅参考

| 视频时长 | 建议篇幅 |
|---|---|
| < 5 分钟 | 300–600 字 |
| 5–20 分钟 | 600–1500 字 |
| > 20 分钟 | 1500 字以上，按章节组织 |

## 收尾

- 笔记生成后，用 `present_files` 交付 `summary.md`、转写文本和视频文件。
- 大文件（视频、音频）**默认保留**，主动询问是否需要删除——
  删除虽省空间，但拿不回来。
- 只在用户明确要求时才删除原视频和音频。
